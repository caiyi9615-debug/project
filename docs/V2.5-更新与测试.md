# Deadline Hunter V2.5 更新与测试

本轮在既有项目上增量修改，主题为快捷收件与今日行动。保留V2.4系列的AI安排、时间证据、图形分析、单位核对和学习通筛选；没有改为另一套独立应用。

## 已完成的变化

1. 新建任务改为快捷弹窗，提供一句话、通知文字和截图入口。支持截图选择、拖拽和粘贴，预览后勾选批量保存。手工仅名称保存和完整表单仍可使用。
2. 保存后提供撤销、查看任务。数据库写入成功后才提示成功；连续点击不重复创建；无效候选不阻止保存其他事项。输入草稿在本页关闭重开时保留，刷新页面不承诺保留尚未保存的草稿。
3. 重复与延期通知仍由用户比较后选择更新、新建或忽略。更新保留历史、原计划和手动完成信息。撤销会拒绝覆盖后续新修改。
4. 首页分为今天实际安排、临近截止、工作完成待提交、过去未完成和以后再做。普通任务可以点击“今天做”，复杂任务显示相应规划入口。顶部统计可点击筛选。
5. 首页展示未来7天已安排执行负载、截止数量和已设置的容量；未知估时、未知容量不编造。点击日期进入日历。分析与历史热力图直接可发现，分析页图形默认展开。
6. 相对日期核实通知原始发布时间，剩余时长核实截图拍摄时间，混合时分别处理。保留“明晚10点”“下周三晚上10点”的明确时刻；24:00归一至次日00:00。缺年份、仅日期和待核实的原有逻辑保留。
7. 桌面600像素快捷弹窗、手机全屏面板，底部操作保持可见；800×600窗口也能保存。服务响应等待超过5秒后解释仍在等待，未伪装成不存在的OCR进度。
8. 产品设计说明按团队信息、作品名称、AI参与工作、核心玩法、设计思路及源代码附件重写，提供可阅读HTML和可编辑Markdown。

## 测试证据的范围

本轮浏览器的AI返回使用可控测试响应，以稳定覆盖成功、失败和边界；真实HTTP未配置密钥时返回明确错误，手动记录继续工作。本轮没有找到可用的既有本地 `.env`，未进行新的真实DeepSeek调用，不将模拟识别计作模型准确率验证。

原项目的真实配置没有被修改或复制进发行包。升级时将程序覆盖到实际使用的旧目录，保留该目录的 `.env`；如果是在Render运行，继续沿用Render已有环境变量。

## 当前限制

- 本地任务按浏览器和网址保存，不能自动跨设备同步；换端口前需要备份迁移。
- AI耗时取决于所配置服务、模型和网络，没有保证10秒内完成识别。
- 本地预览服务未配置真实密钥，AI需在用户现有已配置项目中验收。
- 仅在Edge桌面及模拟手机视口验证，尚未对真实iPhone和安卓机逐机验收。
- 后台推送需要额外配置，本轮没有部署或承诺关闭网页后持续送达。
- 本次没有替用户推送GitHub或更新Render线上版本。


## 独立安装补充

按用户确认，此版放在新目录独立运行，需重新填写本目录的.env；模板和无配置时的默认端口为8795，不占用旧版8790。配置脚本仅在.env不存在时从空密钥模板创建，不覆盖已填写的文件。发行ZIP不包含真实.env，独立安装后的浏览器数据按新端口隔离。
