## 示例与真实功能的边界

视频录制了本版本真实网页的实际操作，使用隔离浏览器中的演示任务，不包含个人任务、API密钥或私人通知。视频中的AI提取和规划返回使用预设样例，已在画面持续标注，不用于证明真实AI响应速度或准确率。数据库保存、时间核实、计划排程、进度勾选与页面同步均通过实际界面操作。

本次改用中文神经网络合成女声 Microsoft Xiaoyi Neural。口播重写为日常对话，并按新语音长度同步调整录屏和字幕；此配音仍为合成声音。视频没有嵌入外部广告、音乐或远程播放器。网页观看需通过start.bat启动的服务打开；离线观看可直接使用MP4文件。静态网页的离线缓存不会自动下载整个视频。
