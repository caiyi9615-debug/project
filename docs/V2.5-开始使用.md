# Deadline Hunter V2.5 开始使用

## 随手添加任务

点击右上角“新建任务”，输入一句话、粘贴群通知或上传截图。截图支持文件选择、拖拽和Ctrl+V粘贴。识别后取消不需要的事项，必要时点“核实时间”，最后“确认并保存”。成功提示提供“撤销”和“查看任务”。

不调用AI时，展开“不使用AI，直接记一件事”，仅保存名称即可；需要手工设置日期等字段，可以打开完整表单。AI失败会保留输入，不影响本地任务管理。没有日期也能保存。

## 今天做什么

- 今天安排：实际安排在今天的未完成步骤，或你点击“今天做”的普通任务。
- 临近截止：未来7天内及逾期事项，不等于今天的执行计划。
- 工作完成但待提交：完成后仍需交到平台的任务。实际提交后点“确认已提交”。
- 之前未完成：可进入安排详情重排剩余步骤；普通任务可以重新选择“今天做”。
- 未来7天负载：未完成执行步骤的估计分钟数、当天截止数及已设置的日容量。未知用时和未设置容量明确标记。

顶部数字可以点击筛选；负载日期可进入相应日历。负载图右上方可进入分析与历史热力图，图形默认展开。

普通作业可以直接完成。实验报告、考试复习、项目分别提供拆分步骤、制定复习计划、项目规划入口。普通任务的可选AI安排放在更多操作中。规划页先使用已知信息和保存过的习惯，只有缺少关键事实时补问。

## 时间依据

“明晚”“下周三”需要通知原始发布时间，不用上传时间或截图拍摄时间代替消息发送时间。“剩余111小时24分钟”需要截图的完整拍摄时间，同一批共享一次。缺少年份保留原时刻并显示建议年份，可批量确认；仅日期不补23:59；24:00换算为次日00:00并保留依据。未知日期可以先保存待核实。

## Windows独立安装

本次新版本放在新文件夹，不覆盖已提交的旧版。

1. 安装Node.js 20或更新版本，将ZIP“全部解压”。
2. 双击 `config-api.cmd`，脚本会创建并打开本版本的 `.env`。
3. 在 `DEEPSEEK_API_KEY=` 后填写自己的密钥，按Ctrl+S保存。模型需与你的服务实际支持一致。
4. 保留 `PORT=8795`，双击 `start.bat`，打开 `http://127.0.0.1:8795/`。
5. 在设置页测试AI连接；修改配置后重启启动窗口。

任务按浏览器和网址保存，因此新端口默认使用独立数据。若需要迁移旧任务，在旧版导出JSON备份，再在新版导入。不要双击 `public/index.html`，不要从ZIP临时目录运行。

## GitHub与Render

上传完整源码，排除 `.env` 和 `node_modules`。构建命令 `npm install --omit=dev`，启动命令 `npm start`，在Render配置自己的服务端环境变量。监听地址使用 `0.0.0.0`，端口由Render提供。详情见 `GitHub与Render部署.md`。本地升级不会自动更新线上网站。
